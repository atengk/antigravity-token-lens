# 本地仅持久化有界稀疏配额采样用于在线趋势分析，离线模式严格屏蔽过期余额

为避免重启 Antigravity 或 Sidecar 后 `Quota Burn Rate` 与历史消耗曲线清零重来，Token Lens 在 `sidecar_data` 目录以单文件原子覆写方式保存最近 7 天内去重压缩后的稀疏 `Remaining Fraction` 采样点（`quota-history.json`）；但当面板处于离线 `Transcript` 模式或未连接本机 Language Server 时，界面仍严格隐藏或置灰配额余额，不回退读取本地历史文件作为当前额度展示。

## Considered Options

- **纯内存保存配额采样**：实现最简单，但每次重启宿主或重载插件都会丢失历史消耗斜率与曲线，导致“跨重启续航分析”能力退化。
- **离线模式顺便展示本地记录的最后一次配额余量**：账号配额属于跨窗口、跨设备的全局动态状态，离线期间用户在其他客户端或设备上的消耗不会写入本机文件，展示旧余额以及基于旧时间算出的倒计时会严重误导用户以为自己仍有余量。
- **有界稀疏持久化 + 仅在线展示**：单文件容量有界封顶（遵守零碎片账本膨胀约束），仅在连接在线 Language Server 时合并历史采样补全趋势图与更稳健的斜率基线。

## Consequences

- 在线模式下，面板重启后可立即延续过去几小时或本周的配额消耗曲线与速率基线，无需重新等待累计掉点。
- 离线 `Transcript` 模式下，用户只能回看历史会话的上下文与 Token 消耗诊断，不会看到误导性的过期账号配额。
