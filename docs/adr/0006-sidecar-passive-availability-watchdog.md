# Sidecar 内置被动 Language Server 可用性巡检与脱敏 Webhook 告警

为解决挂起或排队任务因 VPN 节点地区受限、网络断流或配额耗尽静默失败而难以及时感知的问题，Token Lens 在 Sidecar 后端内置独立后台巡检循环，以 `15s` 会话摘要与 `60s` 配额/状态节奏被动观测本机 Language Server，并在识别到阻断性 `Watchdog Incident` 时通过加签脱敏的 IM Webhook（飞书、钉钉、企业微信及通用 JSON）外发通知。

## Considered Options

- **独立 OS 守护进程 / 系统服务**：虽可脱离 Antigravity 面板生命周期全天候运行，但会引入跨平台安装注册、权限管理与额外发现逻辑，违背插件零安装、零外部依赖的纯原生定位。
- **主动外网 VPN 出口地区探针**：定时请求外部 IP/Geo 接口提前感知节点跳变，虽可早于任务报错预警，但会持续产生外网探测流量且不同代理软件（系统代理 vs TUN）路由语义复杂易误判；因此严格限制为仅被动监听本机 Language Server 真实状态与错误步骤。
- **本机桌面弹窗（Windows Toast）通知**：Antigravity 宿主本身已具备桌面级提醒能力，用户在切换节点或离开电脑时核心诉求是跨端/移动可达，重复弹出桌面通知只会造成干扰，故专注外发 IM 群机器人与 Webhook。

## Consequences

- 巡检前提是在重启 Antigravity 后打开过一次 Token Lens 面板以拉起 Sidecar 进程；激活后即使切走面板标签页，后端仍可持续巡检。
- 启动首次全量扫描仅建立内存基线，绝不针对历史既有失败会话补发旧账告警；相同故障指纹默认 `10` 分钟冷却并支持短窗合并与恢复通知。
- Webhook URL 与加签 Secret 仅落盘于本机受限文件（`0o600`），前端回显强制掩码且导出快照彻底剥离，外发文案严格脱敏（绝不含对话正文、源码或本地路径）。
